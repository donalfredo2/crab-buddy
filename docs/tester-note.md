# A note for crab-buddy testers

A ready message for the 2 or 3 people trying crab-buddy for a week. Copy it, change what you like, and send it.

It deliberately doesn't say what the crab shows. The first question is "what did you notice first?", and listing the features would answer it for them.

---

Hi! Could you help me test a small Claude Code plugin I made? It's a pixel crab that lives above your prompt while you work.

**Install** (needs Claude Code 2.1.309 or later). Type this at the Claude Code prompt:

```
/plugin install crab-buddy --marketplace donalfredo2/crab-buddy
```

Then start a new session. If you installed it before, run `/plugin marketplace update crab-buddy` instead.

**Then just use Claude Code as normal for a week.** If anything bugs you, switch it off; `/crab help` shows how. A switched-off feature is useful to me, not a failure, so please be brutally honest.

In a week I'll ask you three quick things:

1. What did you notice first?
2. What did you turn off, and why?
3. Is it still on?

And a week after that, just: is it still on?

Anything before then: `/crab feedback` gives you a link. Thank you! 🦀

---

## For you, before you send it

- Put two reminders in your calendar now: day 7 for the three questions, day 14 for "is it still on?". Nothing in the plugin reminds you, and day 14 is the answer that matters most.
- Ask "what did you notice first?" before you show or explain anything. Once you've mentioned the red flag, nobody can unsee it.
