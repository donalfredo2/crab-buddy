# A note for crab-buddy testers

Thanks for trying crab-buddy for a week. Copy this, change what you like, and send it.

---

Hi! I'd love your help with a small Claude Code plugin I made: a pixel crab that lives above your prompt and shows what Claude is doing (how full the context is, when Claude is waiting for you, your usage limit).

**Install** (Claude Code 2.1.309 or later), at the prompt:

```
/plugin install crab-buddy --marketplace donalfredo2/crab-buddy
```

Then start a new session. `/crab help` lists the commands.

**Please just use Claude Code as normal for a week.** Turn off anything that bugs you (`/crab help` shows how). That's useful to me, not a failure.

After a week I'll ask you three things:

1. What did you notice first?
2. What did you turn off, and why?
3. Is it still on?

And one more question a week later: is it still on? That one tells me whether it's worth using every day.

Anything before then: `/crab feedback` gives you a link to tell me.
